# Scheduler

## 任务模型（版本 6）

- **TODO 是独立的清单，不属于某一天。** 先创建，之后再分配日期；分配的日期就是它的截止日期（DDL），也可以一直不分配。
- 每个 TODO 有**永久编号** `#N`：创建时分配，改截止日期、改状态都不变，删除后也不会被复用。日志、笔记都用它引用任务。
- 左侧清单显示**全部 TODO**，按截止时间从早到晚排列，分为「已逾期 / 今天 / 明天 / 未来 7 天 / 更晚 / 未设截止日期 / 已完成」。在日历里选中某一天，清单会滚动到那天截止的第一项，并在这些任务左侧显示强调线。
- 日历只在**截止日期那天**显示任务。把任务拖到日历某一天，就是把那天设为它的截止日期（保留原来的时分）；也可以点任务右侧的日历按钮设置。新增任务时写「明天 15:00 开会」，识别出的日期同样成为截止日期。
- 从旧版本升级时，原来「所在的那一天」会成为没有截止日期的旧任务的截止日期，并按日期、顺序补上编号；原文件另存为 `Backups/before-ddl-migration-v5.json`。

## 笔记

`⌃N`（可在设置里改，或日历标题栏的笔记按钮）打开 / 关闭笔记视图：左边是有笔记的任务（按最近更新排序），右边是这个任务名下的全部日志，按日期分组，含图片。底部可直接给选中的任务追加笔记（支持 `⌘V` 粘贴图片），也能复制成 Markdown。笔记视图不显示专注计时的开始、结束记录。笔记是一个独立窗口，不再是 sheet：可以拖边缘随意调整大小（最小 640×420），大小和位置会被记住；窗口没有红绿灯按钮，快捷键或 `Esc` 关闭，拖动空白处移动；主窗口用 `⌃⌥D` 隐藏时它会一起淡出，再显示时一起回来。

## 标签

标签用来把零散的小待办归到同一个大主题下，再一次看到它们所有的笔记。标签是可选的：新待办默认没有标签，也没有截止日期。

- **添加：** 新建待办时直接写 `#标签`（例如 `整理方法部分 #论文`），输入框下面会预览识别出的标签；也可以点待办行上的标签按钮 🏷，打开选择页——已有的标签是圆角矩形，选中的高亮，点一下切换，下面的输入框可以建新标签，`保存` / `取消`。在待办标题里改写 `#标签` 也会移到标签里。
- **规则：** 标签不含空格，不区分大小写；纯数字的 `#3` 仍然是任务编号，不算标签；`C#`、网址里的 `#` 也不算。用 `/` 分层：`论文/方法` 属于 `论文`，看 `论文` 时包含它的子标签。
- **看笔记：** 笔记窗口左边多了「标签」一栏，点一个标签，右边按日期汇总带这个标签的所有待办的笔记，每条标明来自哪个待办；点待办行上的标签也会直接跳过去。搜索框输入 `#标签` 只找标签。主窗口的搜索（🔍）里输入 `#标签`，会列出带标签的待办和它们名下的日志。
- **日志也带标签：** 每条关联了待办的日志（包括专注期间自动关联的日志、专注开始 / 结束记录）都会记下待办当时的标签。待办之后改了标签，笔记跟着待办走；待办被删除后，日志里记下的标签仍然能找到它们。
- **命令行：** `sched tags`、`sched notes 论文`、`sched logs --tag 论文`、`sched tasks --tag 论文`；`sched todo "写报告 #论文"` 会带上标签（`#` 要加引号，bash 里它是注释）。

## 拖动排序

左侧待办清单里，按住每一行右侧的六点把手上下拖动：这一行跟着指针走（略放大、带阴影），其他行实时让出位置，松手后滑进新位置，类似歌单排序。拖到清单上下边缘会自动滚动。右侧月历格子里同一天的任务顺序和左边清单保持一致，左边拖动后日历立刻跟着变。排序只在同一分组内进行（比如「今天」里的几项互相换位置），不会跑到别的分组；要改截止日期，把任务向右拖到日历上，或点行上的日历按钮。手动排过的位置会保存，`⌘Z` 可撤销；给任务改了截止日期后，它的手动位置作废，重新按截止时间排。开启「减少动态效果」时没有滑动动画，松手直接换位。

## 命令行 `sched`

安装后在任何终端里都能用 `sched`（安装脚本把它链接到 `~/.local/bin`；Scheduler 内置终端还会自动把它加进 `PATH`）。

**查看**（直接读数据文件，应用不需要在运行；只读，不会改任何文件）：

```
sched logs [-t 3] [-d 昨天] [-k block] [-g 公式]   日志列表，按日期分组，可点击的链接
sched show <id>                                    一条日志的完整内容，含图片
sched notes 3 [--md]                               某个任务名下的全部笔记；sched notes 论文 是标签「论文」名下所有待办的笔记
sched tasks [--all] [--tag 论文]                   任务列表：编号、截止、笔记数、专注时长、标签
sched tags                                         所有标签：待办数、笔记数
sched pick [筛选]                                   交互式选择：↑↓ 移动，/ 搜索，回车查看详情，i 看图，y 复制，q 退出
sched status                                       数据概况，应用是否在运行
```

筛选 `-t 任务编号`、`-d 日期`、`--since/--until`、`-k note|done|block|plan`、`-g 文字`（也搜任务标题和截图里识别出的文字）、`--with-images`、`--focus`（含专注记录）、`-n 条数`（不加筛选时默认最近 30 条，`-a` 不限）。日期可写 `2026-10-07`、`10-07`、`today`、`yesterday`、`7d`。输出可选 `--md`、`--json`、`--porcelain`（制表符分隔，给 fzf、awk 用）；输出被管道接走或设了 `NO_COLOR` 时不着色。

**写入**（经运行中的应用，通过数据目录里的 Unix socket `scheduler.sock`，权限 0600，只有当前用户能连；应用没开会自动启动，`--no-launch` 关闭）：

```
sched log [-t 3] [-i 截图.png] 正文        记一条日志；正文可以 /done /block /plan 开头，或以 #3 开头关联任务
echo 内容 | sched log -                    从标准输入读
sched todo 明天 15:00 开会 提前30分钟      添加待办，和快速添加窗口一样会解析日期、时间、提醒
sched done 3  /  sched undone 3            完成 / 取消完成
```

写入和界面里的行为一致：专注计时期间不指定任务的日志会关联到专注的任务；明确指定任务的 `/done` 同时完成任务；写进去的内容立刻出现在界面里，可以 `⌘Z` 撤销，并且立刻落盘，紧接着 `sched logs` 就能读到。写入走应用而不是直接改数据文件，是因为应用不监视文件变化，直接改会被它下一次保存覆盖。

**图片**：`sched show` 和 `sched logs --images` 在支持内联图片的终端里直接画出来（Scheduler 内置终端、iTerm2、WezTerm 用 iTerm2 协议，Ghostty、Kitty 用 Kitty 协议），按终端宽度缩小、完整显示不裁剪；系统自带「终端」和 tmux 里不支持，改为打印可点击的文件路径。可用环境变量 `SCHED_IMAGES=iterm2|kitty|none` 强制指定。

**配合 fzf**：`sched logs --porcelain -a | fzf --delimiter '\t' --with-nth 2.. --preview 'sched show {1}'`

**zsh 用户注意**：zsh 自带一个叫 `sched` 的内置命令（定时任务），在 zsh 里会盖住 PATH 里的 `sched`。所以同一个程序也以 `scheduler` 的名字安装（`scheduler logs`、`scheduler log ...`），所有 shell 里都不冲突；想在 zsh 里继续敲 `sched`，在 `~/.zshrc` 里加一行 `disable sched` 即可。Scheduler 内置终端里已经自动处理，不用设置。

没有命令时，检查 `~/.local/bin` 是否在 `PATH` 里（安装脚本会提示）。

## 专注计时

任务标题里带网页或本地文件链接时，任务行出现播放键。点它会：打开链接、在屏幕左上角显示一个不抢焦点的小计时窗口、在终端日志里记录开始时间。之后每秒检查前台：连续 2 秒不在目标页面（切换到别的应用，或 Safari 当前标签页换成了别的页面）就停止计时，并在日志里记下用时和原因；也可以手动点停止。刚打开页面的前 6 秒是宽限期，用来适应重定向，并以实际打开的页面为准。

在 Scheduler 里记笔记（Scheduler 在前台，包括 `⌃⌥L` 快速窗口）**不算离开**，计时照常累计；回到浏览器后再按目标页面检查。小窗只显示计时、任务名称和停止按钮。

专注计时期间，**每一条日志都会自动关联到正在专注的任务**：快速日志窗口（`⌃⌥L`）、主窗口的日志输入框都一样，记完后在笔记视图里就归到这个任务名下。快速窗口的提示行和日志输入框上方会写明「专注中：关联到 #N …」。规则：你明确指定了任务（正文开头写 `#N`，或用「关联任务」选了一个）时以你指定的为准；专注只是兜底，所以 `/done` 不会替你把专注中的任务标记完成。计时结束、或专注的任务被删除后，日志恢复为不关联。

点任务里的网页链接（包括专注计时的播放键）时，如果这个页面已经在 Safari 的某个标签页里开着，会直接切换到那个标签页，不重新加载，网页滚动位置和 PDF 页数都保留；没开着才新打开。

检测 Safari 当前页面地址需要「自动化」权限：第一次使用时系统会询问是否允许 Scheduler 控制 Safari，只读取地址。未授权时只能检测是否离开 Safari。专注记录会出现在终端日志中（可用 `/filter #N` 查看），但不进入笔记视图。

## 快速记录窗口

（以下是默认组合，都可以在 `⌘,` 设置里点组合框后直接按下新的键来修改，会检查冲突，也可一键恢复默认；至少需要一个 ⌃ ⌥ ⌘。）`⌃⌥D` 在任何应用里打开 / 隐藏 Scheduler 主窗口，没有动画：Scheduler 不在前台时，在你**当前所在的桌面**（鼠标所在的屏幕和 Space）打开并调到最前面，不会把你切到 Scheduler 原来所在的桌面；已在前台时再按一次就隐藏，并回到刚才的应用（比如继续看网页，专注计时不受影响）。`⌃⌥D`（主窗口）和 `⌃⌥T`（终端）互相独立：各自只开关自己那一组窗口，收起一边时另一边如果还开着，焦点就交给它，不会跟着消失；只有 Scheduler 再没有可见窗口时才回到刚才的应用。终端在前台、主窗口在后面时，按 `⌃⌥D` 是把主窗口调到前面，而不是隐藏它。打开和隐藏是柔和的淡入淡出（开启系统「减少动态效果」时直接切换）。主窗口没有红绿灯按钮，用 `⌘W`、`⌘M` 或这个快捷键关闭 / 收起。隐藏时只收起主窗口，不隐藏整个应用，所以不会影响快速记录窗口。`⌃⌥T` 打开 / 隐藏**内置 zsh 终端**：真正的 PTY 终端（登录 shell，起始目录是主目录，能运行 vim、htop，也能在 app 里和 agent 对话），不是日志输入框。

- **顶部工具条：** 每个终端窗口顶部常驻「新标签页 ⌘T」「新窗口 ⌘N」「关闭 ⌘W」三个按钮，右侧列出切换、跳转、清屏和隐藏的快捷键（窗口窄时自动精简）；菜单栏的「终端」菜单也有全部操作。
- **默认三窗格：** 每个终端窗口（和每个新标签页）是一个窗口里三个独立的 zsh 窗格——左边上下两格，右边一整栏，用来同时开着几个 agent 和一个普通 shell。点击窗格或按 `⌘[` / `⌘]` 在窗格间切换，当前窗格有高亮边框，分隔线可拖动调整大小。在某个窗格里输入 `exit` 只会拿掉这个窗格，其余自动补位，全部结束后窗口才关闭。设置里可以改成「单窗格」。
- **分割窗格：** 点工具条的「右分栏 ⌘D」「下分栏 ⇧⌘D」，或按快捷键，把当前窗格分成两个；新窗格拿走一半空间、从当前目录开始并获得焦点。可以反复分，横竖混合（比如左边一栏、右边上下两格）。`⌥⌘W` 关闭当前窗格（里面有程序在运行会先确认，最后一个窗格就关闭窗口），分隔线可拖动，窗格太小时不再分。菜单栏「终端」里有全部这些操作。
- **多窗口、多标签页：** `⌘N` 新开一个独立终端窗口，`⌘T`（或标签栏的「+」）在当前窗口新开一页，`⌘W` 关闭当前页 / 窗口，`⌘⇧[` / `⌘⇧]` 切换页，`⌘1`–`⌘9` 跳到第几页，`⌘K` 清屏。标签页可以拖出来变成新窗口。新页和新窗口从当前页所在的目录开始。
- **这几个快捷键归终端：** 原来的「新建待办 `⌘N`」「回到今天 `⌘T`」「插入链接 `⌘K`」不再占用这些键（菜单项还在，只是没有快捷键）；终端窗口在最前面时，主窗口的其他快捷键不会触发。
- **持久：** `⌃⌥T`（或再按一次）只是把**全部**终端窗口一起显示 / 隐藏，shell 和里面运行的程序一直保留，再打开还是同一批。只有输入 `exit`、关闭页 / 窗口或退出 Scheduler 才会结束 shell。
- **防误关：** 关闭页 / 窗口，或退出 Scheduler 时，如果任何一个窗格里有程序在前台运行（比如正在和 agent 对话），会先确认；停在提示符时直接关闭。
- 想让会话在 Scheduler 退出后也保留，可以在终端里用 `tmux`（`tmux attach` 找回）。窗口同样出现在当前桌面。
`⌃⌥L`（日志）在任何应用里呼出快速记录窗口，像 Spotlight 一样：再按同一个键关闭，`Tab` 切换到待办模式，点窗口外也会关闭（Esc 仍可用）。快速添加待办不再有全局快捷键，用菜单栏叶子图标里的「快速添加待办…」或在日志窗口里按 `Tab`。笔记的快捷键（默认 `⌃N`）是应用内快捷键，只在 Scheduler 在前台时生效，也可以在设置里重新绑定。窗口可拖动，位置会被记住。

一个原生 macOS 日历待办应用，使用 SwiftUI / AppKit，运行时无需联网或账户。唯一的第三方依赖是内置 zsh 终端用的开源库 [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm)（MIT），首次构建需要联网下载一次。支持 macOS 13 及以上版本。

## 安装与运行

需要 Xcode 或 Swift 命令行开发工具。在此目录运行：

```sh
bash scripts/install.sh
```

应用安装到 `~/Applications/Scheduler.app`，可在 Spotlight 中搜索 `scheduler`。安装后自动打开并启用登录启动。已有版本更新前，请按 `⌘Q` 退出 Scheduler。这个应用以前叫「Dayleaf 日页」，改名后安装脚本会自动移除旧的 `~/Applications/Dayleaf.app`；Bundle ID（`local.dayleaf.app`）、数据文件夹 `~/Library/Application Support/Dayleaf` 和源码里的模块名都没有改，所以数据、通知和 Safari 自动化授权、快捷键设置、窗口位置都原样保留。仅构建可运行 `bash scripts/build.sh`。

## 布局与日历

- 上方左侧为待办清单、右侧为月历；下方为横跨整个窗口的终端日志与复盘。清单和终端可以分别折叠，月历始终显示。清单首次默认收起，点击任意日期就展开对应清单；日期标题旁的侧栏按钮可收起，月历标题旁的侧栏按钮可重新展开。终端右上角向下箭头可收起为底部细条，点击细条重新展开。折叠状态和分隔比例会记住。
- 分隔线附近有 12pt 拖动热区；上方竖线调整清单和月历宽度，横线调整整个上方区域与终端的高度。交界处有 24pt 控制点，可向任意方向拖动，同时调整宽高；折叠面板不会丢失之前的尺寸或记录。
- 月历默认显示当天安排和当天截止的全部任务，以小字号短名称逐条预览，不限制条数。任务较多时所在周自动增高，超出面板后统一滚动月历，日期格内不单独滚动。右上角数字表示当天安排事项的「已完成 / 总数」。
- 首次点击日期立即选择当天，不等待双击判定；双击展开完整清单。展开界面同时包含当天安排和当天截止的事项；新增默认设为当天截止，可取消该选项。切换日期只读取记录，月历索引在任务变化后更新，不随点击重新扫描全部任务。
- 右上角菜单可以开启「月历仅显示截止事项」。任务始终使用同一份数据，清单和月历的完成、编辑、删除同步；默认不再因为任务没有截止日期而隐藏其名称。
- 月历以 10pt 小字号显示任务短名称。在任务右侧日历按钮打开的详情中填写月历短名称，点击保存生效；清空短名称恢复原标题，不删除任务。没有设置短名称时自动以正文截短显示。悬停月历条目可看全文，原任务只有一个链接时，短名称仍可直接打开它。
- 清单和月历采用 GitHub 风格配色，跟随系统浅色或深色模式；下方终端固定近黑色背景，日志流与输入区为纯黑，搭配等宽字体、灰白正文和绿／黄／蓝状态色。

## 鼠标与键盘操作

双击已有任务、日志文字开始编辑，单击复盘区即可编辑，日志也可点击右侧铅笔按钮。单击任务选中并显示蓝色边框，单击链接直接打开，勾选框直接切换完成状态。新增待办和日志输入框点击即可输入。应用不再区分 NORMAL / INSERT，也不拦截 `i`、`Ctrl+[`、`Ctrl+B` 或 `Ctrl+W`。中文输入法组词时，回车、Esc 和方向键交给输入法处理。

| 快捷键 | 操作 |
| --- | --- |
| `Esc` | 保存当前条目编辑并结束编辑；未提交的新输入保留为草稿 |
| `Enter` | 提交事项并继续输入下一条 |
| 空白新事项输入框中 `Backspace` | 编辑最后一条可见事项 |
| `⌘N` | 聚焦待办面板的新增输入框 |
| `⌘K` | 在当前任务文本选区插入 Markdown 链接 |
| `⌘F` / `⌘T` | 搜索任务、日志和总结 / 回到今天 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做；文本输入中撤销文字，其他位置撤销任务操作 |

双击任务文字修改原文；Enter、失焦或 Esc 保存。清空标题会删除事项，可撤销。隐藏已完成只改变显示，不自动重新排列清单。复盘单击即可编辑，失焦或 Esc 结束编辑；总结和草稿自动保存，关闭窗口或退出时立即落盘。

## 终端式日志与复盘

下方默认是紧凑的终端日志流，每行显示 `[HH:mm:ss] 内容`，关联任务时显示 `[HH:mm:ss] [#编号 任务名称] 内容`。纯黑背景、等宽字体，不额外显示类型列；类型通过时间戳颜色区分。右侧编辑与删除按钮始终占据固定位置，平时淡显、悬停亮起，不再切换鼠标命中区域或遮住正文。底部 `❯` 输入框点击即可输入，Enter 追加一条并继续输入；Esc 退出输入框，未提交的输入保留为当天草稿。日志时间记录实际输入时刻，记录归属当前选中的日期。

```text
[15:10:04] 开始阅读 EuroSys 论文
[15:32:18] 整理完方法部分的笔记
[15:40:06] 复现实验缺少配置
[15:45:22] 明天补对照实验
❯ /block 复现实验缺少配置
```

| 输入 | 行为 |
| --- | --- |
| 普通文字或 `/note 内容` | 随手记录 |
| `/done 内容` | 记录进展；关联任务后同时将任务标记完成 |
| `/block 内容` | 记录卡点 |
| `/plan 内容` | 记录明日计划 |
| `/summary` | 生成按进展、卡点、明日计划和随手记录分组的复盘草稿 |
| `/link #1` | 把之后的日志关联到当天清单的 #1 任务；`/link` 或 `/unlink` 取消关联 |
| `/filter #1 #3` | 日志区只显示这些任务相关的日志（跨日期）；`/filter` 清除 |
| `/help` | 显示命令帮助 |

命令里可以直接带编号：`/done #1 完成了方法部分`、`/block #2 卡在配置`，或以 `#2 内容` 开头，只关联这一条日志。编号指当天清单里的 #N；命令里写了不存在的编号会提示，纯文字开头的 `#N` 若没有该任务则当作普通文字。日志区右上角的筛选按钮可勾选任务，筛选时按日期分组显示这些任务的全部日志。

### 日志图片

在日志输入框或快速记录窗口（`⌃⌥L`）中 `⌘V` 粘贴截图、网页复制的图片或 Finder 里复制的图片文件，也可把图片文件拖到日志区。输入框上方显示缩略图，可点 ✕ 移除；回车后图片随这条日志保存，只有图片、没有文字也可以提交。带图的日志行末尾显示图片数量，**单击这一行**在下方展开缩略图，点缩略图查看大图（← → 切换，可复制或在「预览」中打开）。

图片长边缩到 2048px 以内，保存为 `~/Library/Application Support/Dayleaf/Images/` 下的独立文件，日志里只记录文件名，不会让 `journal.json` 变大。截图里的文字在本机用系统 Vision 识别（不联网），搜索时可以搜到。启动稍后会清理不再被当前数据、每日快照或启动备份引用的图片。同时带文字的剪贴板内容（例如从表格复制）仍按文字粘贴。

点每条日志右侧的铅笔，右边的复盘区会临时变成这条日志的编辑框：Enter 保存，⇧Enter 换行，Esc 取消；双击日志正文仍可就地修改。

任务编号 `#N` 是永久的（见上文「任务模型」），隐藏已完成、改截止日期都不会改变它。点输入框右侧「关联任务」，从带编号和名称的列表选择任务，输入框上方会显示当前关联；下一条普通 INFO 或其他类型日志会显示该任务。提交后清除选择，避免后续记录误关联。关联依据任务 UUID，排序不会串项；跨日移动后日志显示任务的新日期和编号，任务删除后显示记录时的编号及标题快照并标注已删除。点击日志里的任务标签可跳到对应日期并选中任务。

已关联时，可直接输入 `/done`，使用任务标题作为日志内容；任务已经完成时不会被取消勾选或重复生成周期任务。日志中的 Markdown 网页与 PDF 链接仍可点击。

`↑` / `↓` 调取当天的输入历史，回到最新位置会恢复原草稿；`Tab` 补全命令。双击日志正文或点击右侧铅笔按钮修改记录，垃圾桶按钮删除记录，修改保留原时间戳。删除一条历史日志不会改变任务当前状态。退出文本输入后 `⌘Z` 可撤销日志操作；添加 `/done` 日志与任务完成作为一次操作撤销。

下方终端分为左右两栏：左边是日志流和输入，右边常驻显示每日复盘（保留原有总结），单击即可编辑；中间分隔线可拖动调整宽度。终端只对今天及以前的日期显示，选中未来日期时隐藏。输入 `/summary` 或点击右上角整理按钮先查看草稿，草稿可直接修改，确认后追加到已有总结或选择替换；不会自动覆盖原文。整理在本机按类别汇总记录，不依赖外部服务。日志、草稿、关联信息和复盘都纳入 JSON 导出、备份恢复与搜索。

## 链接与日程

- `[论文](https://arxiv.org)` 渲染为蓝色圆角链接块，文字和内边距均可点击，用 Safari 打开；直接输入网址也会识别。按钮有完整的点击热区与悬停反馈，普通按钮至少 30pt，日历紧凑按钮至少 22pt。
- `[eurosys](file:///Users/example/Reading/eurosys27-extra-paper1384.pdf)` 使用 Safari 打开本地 PDF；其他本地文件使用 macOS 默认关联应用。`⌘K` 也支持绝对路径和 `~/`，会读取剪贴板中的地址，并在原选区插入别名。
- 任务采用单行主布局：左侧勾选，中间正文，右侧仅保留日历设置、删除、六点抓手三个操作，抓手位于最右且垂直居中。操作区至少 30pt，悬停显示用途。选中的条目显示蓝色边框；正文双击编辑，月历短标题在日历设置中修改。任务和日志不使用条目右键菜单。
- 清单任务和月历预览都是可拖动的圆角块。抓手、正文和清单块的空白边缘显示张手光标，拖动时变为握手。抓手轻移即可拿起；原条目淡出，浮动预览带透明度与阴影，放下或取消时以短弹簧动画过渡。按钮区域不参与拖动。
- 左侧可上下拖动排序，蓝色插入线表示将放在目标任务之前或之后，拖到底部空白处可放到末尾；也可跨日期拖动，目标日期高亮。拖动链接不会误打开网页，单击仍可打开。排序会保存，排序和跨日移动均可撤销。
- 只接受 Scheduler 任务拖放。应用内拖动直接使用当前任务 ID，在放下时立即更新位置，不等待异步载荷读取或磁盘写入；保存合并延后 250ms，退出时立即落盘。放回原月历日期不改变顺序，取消拖动不修改数据。安排日期和截止日期分别保存，移动不会悄悄修改截止日期。
- 日历按钮可直接设置安排日期、截止日、具体时间、提醒、每天/工作日/每周/每月重复。完成重复事项后生成下一次，保留历史且不会因反复勾选重复生成。
- 「未完成」「即将截止」「已逾期」和搜索可跨日期查看任务。即将截止包含未来七天；全天截止事项当天结束后才算逾期。
- 保存启用提醒的事项时才请求 macOS 通知权限。全天事项默认上午 9 点提醒，指定时间的事项按截止时刻及提前量提醒；完成或删除会取消未触发的提醒。状态栏铃铛警告可打开通知设置。实际通知还受系统权限与专注模式影响。
- 菜单中「登录时自动启动」控制自启，登录后由 launchd 启动。关闭窗口后可点 Dock 图标重新打开；`⌘Q` 完全退出。

## 数据与备份

数据位于 `~/Library/Application Support/Dayleaf/journal.json`，原子写入；连续输入合并 250 毫秒内的磁盘写入。旧版数据自动迁移到版本 5，原总结原样保留。启动时另存 `journal.backup.json`，每日首次保存生成 `Backups/YYYY-MM-DD.json`，保留最近 30 个有保存活动日期的快照。

菜单「导出为文件夹…」生成一个包含 `journal.json` 和日志图片（`Images`）的文件夹；在「备份与恢复」中可选择快照，或导入这种文件夹（也可以只选单个 JSON），预览天数、事项、日志和总结数量后恢复，图片一并复制回来。恢复前自动另存 `before-restore-*.json`，这些恢复前备份独立保留。保存失败会提示并可重试；文件损坏或版本不兼容时停止写入，仍可导入有效备份恢复。

每日记录使用本地公历日期 `YYYY-MM-DD`。新待办草稿随日期保存，退出后也会保留；清单与展开日历共享当天草稿。

登录启动配置为 `~/Library/LaunchAgents/local.dayleaf.app.plist`，使用 macOS 的 launchd 在登录时打开本应用，不会在主动退出后反复重启。卸载前在应用中关闭登录启动，再删除应用；记录文件独立保留。
