# Scheduler

macOS 原生的待办、日志和笔记应用（SwiftUI / AppKit），数据全部保存在本机。

- **待办**：每个待办有永久编号 `#N`，可设截止日期、提醒、重复，可加 `#标签`。直接写「明天 15:00 开会 提前30分钟」会自动识别。左侧清单拖右侧把手排序，日历格子里的顺序跟着变。
- **专注计时**：给待办里的链接计时，专注期间写的日志自动归到该待办名下。
- **当天日志**：选中某一天按 `⌘J`（或日期旁的按钮）打开 sheet，按时间顺序列出当天所有日志，可在里面写、改、删、关联待办、打标签、多选批量处理、复制；右边是当天复盘，单击即可编辑，也可一键按「进展 / 卡点 / 明日计划」整理草稿。sheet 里可以翻前后一天，拖边缘调整大小，`Esc` 或 `⌘J` 关闭。主界面只有待办清单和月历。

## 三个入口

| 快捷键 | 功能 |
| --- | --- |
| `⌃N` | **笔记**（全局）：标签是笔记本，待办是里面的章节。可新建空标签、直接往标签里写，也可按待办或按日期查看；每条笔记可复制、编辑、删除、更换关联待办。无标题栏按钮，`Esc` 或再按一次关闭。各窗口互相独立，`⌃⌥D` 收起主窗口不影响它。 |
| `⌃⌥L` | **快速日志**：在任何应用里呼出，写一条日志（粘贴大段内容时输入框自动增高，`⇧回车` 换行），可选标签，`⌘V` 可贴图，`Tab` 切到快速添加待办。支持 `/done` `/block` `/plan` 开头，`#3` 开头关联任务。 |
| `⌃⌥T` | **内置终端**：zsh，可分栏、多标签。 |

另有 `⌃⌥D` 显示 / 隐藏主窗口。全局快捷键均可在设置里重新绑定（注意 `⌃N` 会占用其他应用里的同一组合键）。

## 标签

写 `#论文` 或点待办行上的标签按钮选择。标签不含空格，不区分大小写；纯数字 `#3` 是任务编号，不算标签；`论文/方法` 属于 `论文`。在笔记里点标签，或在搜索框输入 `#标签`，就能看到带该标签的所有待办及其笔记。点每条日志最右边的圆圈选中它，选中几条后日志区底部出现操作栏，可批量加 / 去标签，或批量关联到某个待办（一次 `⌘Z` 撤销整批）；日志自己的标签不依赖待办。标签可以先建成空的（笔记窗口「标签」旁的 +），之后在标签页底部直接写，不必关联待办。批量栏和各处的「关联待办」都是带搜索的选择器（标题、编号、`#标签`），专注中和最近用过的排最前。日志行、笔记行和批量栏都能一键复制文字（不含图片）。

## 命令行 `sched`

安装后在任何终端可用（zsh 里自带同名内置命令，请用 `scheduler`，或在 `~/.zshrc` 加 `disable sched`）。

```sh
sched logs [-t 3] [--tag 论文] [-g 关键词]   日志列表
sched notes 3 | 论文                          某个任务 / 标签的笔记
sched tasks / tags / status                   任务、标签、概况
sched pick                                    交互式选择
sched log "内容" / todo "明天 开会" / done 3   写入（经运行中的应用，必要时自动启动）
```

读取不需要应用在运行，写入通过本机 socket 交给应用。`sched help` 查看全部用法。

## 安装

需要 Xcode 或 Swift 命令行工具：

```sh
bash scripts/install.sh
```

应用装到 `~/Applications/Scheduler.app`，命令行装到 `~/.local/bin`。更新前请先退出 Scheduler。运行测试：`swift test --disable-sandbox`。

## 数据

位于 `~/Library/Application Support/Dayleaf/`：`journal.json`（原子写入）、`Images/`，每日自动备份到 `Backups/`（保留最近 30 个）。菜单里可导出、从备份恢复。
